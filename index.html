Héritage

« Que ce soit dans le livre, le journal, le magazine, le tableau, l’écran, l’image est toujours prisonnière, enfermée dans un cadre. Le monde réel, qui est partout, avec le ciel, le sol, ses jeux d’ombres et de lumières, c’est l’Image Totale© »
- Albert Plécy
